Reverse Engineering → Port Blueprint

Windows 11「实时辅助字幕 / 实时翻译」 把微软 195 MB 的私有离线模型拆开看，然后在 Android 上重建一条等价的流水线

宿主 Win11 25H2 · 26200.9711 引擎 Azure Speech SDK · embedded 模型 RNN-T 流式 · 4002 BPE 出帧 40 ms 音频 WASAPI 进程回环 权重 不可再分发

1组件分层

从 `System32` 的存根一路点到 ONNX 张量：一共 5 层，层与层之间是 WinRT 激活 + C API 调用。

6移植的三个硬约束

ALLOW_CAPTURE
目标 App 可主动拒绝被采集，且失败时给的是静音不是错误
~195 MB
Windows 单语种模型体积；Android 换开源后可压到 40–100 MB
NO APPBAR
Android 没有"让其他窗口让位"的机制，贴边停靠需放弃
LICENSE
微软权重禁用；开源替代须逐个核对训练数据许可
